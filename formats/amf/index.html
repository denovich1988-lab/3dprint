AMF file (.amf)

Additive Manufacturing File

AMF is an XML format for 3D printing that was largely replaced by 3MF.

What it stores

Meshes, materials, colours, units.

Software that uses AMF

Older PrusaSlicer and Slic3r versions.

Questions and answers

How do I open a .amf file?

Older PrusaSlicer and Slic3r versions can open AMF files. You can also open it in your browser with our 3D viewer, without installing anything.

What does a AMF file store?

Meshes, materials, colours, units.

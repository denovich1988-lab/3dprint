FBX → OBJ 변환기

브라우저에서 FBX 파일을 OBJ로 변환하세요. 3D로 미리 보고 크기를 확인한 뒤 다운로드하면 됩니다. 무료이고 가입이 필요 없으며, 파일은 기기 밖으로 나가지 않습니다.

파일은 기기에서 처리되며 절대 업로드되지 않습니다.

사용 방법

  1. FBX 파일을 3D 미리보기에 끌어다 놓거나 “모델 업로드”를 클릭하세요.
  2. 미리보기와 크기를 확인하세요. 모델이 이상해 보이면 크기 배율이나 위쪽 축을 조정하세요.
  3. “OBJ로 변환”을 클릭한 뒤 OBJ 파일을 다운로드하세요.

FBX에서 OBJ로의 변환

FBX는 게임 에셋과 Mixamo 캐릭터에서 흔히 쓰입니다. OBJ는 메시와 UV를 유지하지만 스켈레톤과 애니메이션은 OBJ에 포함되지 않으므로, 모델은 현재 포즈로 내보내집니다.

FBX 파일이란?

FBX는 애니메이션과 게임을 위한 Autodesk의 교환 형식입니다. 메시, 스켈레톤, 애니메이션, 재질을 담을 수 있습니다. FBX 자세히 보기 (영어).

OBJ 파일이란?

OBJ는 거의 모든 곳에서 지원되는 텍스트 기반 3D 형식입니다. 꼭짓점, 면, 텍스처 좌표를 저장하고, 재질은 별도의 .mtl 파일에 들어갑니다.

형식별 저장 내용

FBX

메시, 리그, 애니메이션, 카메라, 재질.

주요 사용처: Maya, 3ds Max, Unity, Unreal Engine, Mixamo, Blender.

OBJ

지오메트리, UV 좌표, 노멀, 그룹. 색상과 텍스처는 함께 제공되는 .mtl과 이미지 파일로만.

주요 사용처: Blender, Maya, 3ds Max, ZBrush, 게임 엔진, 포토그래메트리와 3D 스캔 앱.

관련 도구

GLB → OBJOBJ → STLSTL → OBJFBX → STLDAE → OBJglTF → OBJOBJ → GLBFBX → GLB3MF → OBJPLY → OBJSTP → OBJ3DS → OBJ

자주 묻는 질문

무료인가요?

네. 가입도, 워터마크도, 저희가 정한 파일 크기 제한도 없습니다. 아주 큰 파일은 기기의 메모리에 의해서만 제한됩니다.

파일이 업로드되나요?

아니요. 변환은 JavaScript와 WebAssembly로 브라우저에서 실행됩니다. 파일은 기기에서 읽히고 결과도 기기에서 만들어지므로, 서버로 전송되는 것은 없습니다.

FBX를 OBJ로 변환하면 무엇이 사라지나요?

OBJ에 저장되는 것: 지오메트리, UV 좌표, 노멀, 그룹. 색상과 텍스처는 함께 제공되는 .mtl과 이미지 파일로만. FBX가 그 밖에 담고 있는 정보는 사라집니다. FBX는 폐쇄형 형식입니다. 브라우저에서 읽을 수는 있지만 FBX로 쓰려면 Autodesk SDK가 필요해 FBX 내보내기는 제공하지 않습니다.

모델 크기가 이상한 이유는?

형식마다 단위를 다르게 저장합니다. STL은 단위가 없고, glTF는 미터를 쓰며, 3MF와 STEP은 단위를 기록합니다. 결과가 1000배 작거나 크게 보이면 크기 배율에서 다른 옵션(예: “미터 → mm”)을 골라 다시 변환하세요.

모델이 옆으로 누워 있는 이유는?

어떤 형식은 Y를 위로(glTF, OBJ, FBX), 어떤 형식은 Z를 위로(STL, 3MF, STEP) 봅니다. “위쪽 축: 자동”은 대상 형식에 맞게 모델을 회전합니다. 원래 방향을 유지하려면 “그대로 두기”를 고르세요.

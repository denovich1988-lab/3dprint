<h2>What is Prusa Connect?</h2>
<p>Prusa Connect is the online counterpart to PrusaLink. Prusa&#39;s knowledge base describes PrusaLink as the local web interface that lives on the printer, and Prusa Connect as the service that lets you reach your printers from anywhere and manage many of them in one place. Once a printer is added, it reports its state – idle, printing, paused, finished, error – along with temperatures, progress and time left.</p>
<p>From the dashboard you can:</p>
<ul>
<li><strong>Upload G-code</strong> and start a print remotely.</li>
<li><strong>Pause, resume or stop</strong> a running job.</li>
<li><strong>Keep a print queue</strong> so the next job is ready when the plate is cleared.</li>
<li><strong>See camera snapshots</strong> from a connected camera.</li>
<li><strong>Get notifications</strong> when a print finishes or fails.</li>
<li><strong>Group printers and invite users</strong> with different permissions, which is useful for print farms, schools and makerspaces.</li>
<li><strong>Manage files</strong> stored on the printer&#39;s USB drive.</li>
</ul>
<p><strong>Why it matters:</strong> you can start a print from your desk, check it from your phone and stop it if something goes wrong, without walking to the printer.</p>

<h2>How to set up Prusa Connect</h2>
<p>The exact menu names can differ between firmware versions; Prusa&#39;s knowledge base has a step-by-step guide for each printer. The general process on printers with built-in networking is:</p>
<ol>
<li><strong>Update the firmware</strong> to the latest release for your printer.</li>
<li><strong>Connect the printer to your network.</strong> Plug in an Ethernet cable, or set up Wi-Fi from the printer menu. Newer models also accept Wi-Fi details from the phone app over NFC or from a settings file on the USB drive.</li>
<li><strong>Create or sign in to a Prusa Account</strong> at Prusa&#39;s website.</li>
<li><strong>Start the pairing on the printer.</strong> In the network settings, choose the option to add the printer to Prusa Connect. The screen shows a QR code and a code.</li>
<li><strong>Scan the QR code</strong> with your phone or open the link on a computer, sign in and confirm. Give the printer a name and, if you like, put it in a group.</li>
<li><strong>Check the dashboard.</strong> The printer should appear online with its current status.</li>
</ol>
<p><strong>Older MK3-generation printers</strong> need a Raspberry Pi (Prusa documents the Raspberry Pi Zero 2 W fitted inside the printer, or a Pi 3/4 over USB) running the PrusaLink image. You set up PrusaLink first, then register the printer in Prusa Connect from PrusaLink&#39;s setup wizard.</p>
<p><strong>Tip:</strong> if the printer will not go online, check that it has an IP address in the network menu first. Most failures are Wi-Fi problems, not Prusa Connect problems.</p>
<h2>Sending prints from PrusaSlicer</h2>
<p>PrusaSlicer can upload directly to Prusa Connect once you sign in with your Prusa Account. After slicing, choose the option to send the G-code to Prusa Connect, pick the printer, and either start the print right away or add it to the queue. You can also upload a G-code file in the browser.</p>
<p><strong>Tip:</strong> make sure the print profile in PrusaSlicer matches the printer you are sending to. G-code sliced for an MK4S will not print correctly on a MINI+. If you start from a CAD file, our <a href="/step-to-stl/">STEP to STL converter</a> creates a mesh you can slice, and <a href="/3mf-to-stl/">3MF to STL</a> splits projects into plain meshes.</p>
<h2>Cameras and notifications</h2>
<p>Prusa Connect shows camera snapshots so you can check a print from anywhere. Prusa sells its own Buddy3D camera, which connects to the printer and appears in Prusa Connect; Prusa&#39;s knowledge base also describes adding other camera sources. Snapshots refresh at intervals rather than as a continuous video stream.</p>
<p>Notifications tell you when a print finishes, pauses or fails. Prusa&#39;s knowledge base includes a guide for setting up notifications through Telegram, and the Prusa app shows printer status on your phone.</p>
<p><strong>Why it matters:</strong> a camera plus a notification lets you catch spaghetti or a detached print early and stop the job before it wastes a full spool.</p>

<h2>Prusa Connect Local – self-hosted Connect</h2>
<p>Prusa Connect Local is a &quot;local-first&quot; version of Prusa Connect that you run yourself. Prusa&#39;s page describes it as a printer server you download as a single file for Linux, Windows, macOS or Raspberry Pi; larger setups can use Docker and Kubernetes. Printers connect straight to your server, users sign in with accounts on that server rather than a Prusa Account, and Prusa printers need firmware 6.4.0 or newer. When we checked in November 2026 it was labelled a public beta. Prusa publishes the source on GitHub and says it is free for personal use and for small businesses using it internally; larger companies and hosted services need a business licence.</p>
<p><strong>Why it matters:</strong> companies, schools and labs with strict IT rules – or anyone who prefers not to depend on a cloud service – can now get Connect&#39;s multi-printer features without sending print data to Prusa&#39;s servers. Check Prusa&#39;s Connect Local page for current requirements and supported features, as the software is new and still changing.</p>
<h2>Security and privacy tips</h2>
<ul>
<li><strong>Use a strong, unique password</strong> for your Prusa Account and turn on any extra sign-in protection Prusa offers.</li>
<li><strong>Share printers through teams</strong> rather than sharing your login.</li>
<li><strong>Keep firmware up to date</strong>, because network features get fixes with new releases.</li>
<li><strong>Use PrusaLink or Connect Local</strong> if your organisation does not allow cloud services.</li>
<li><strong>Remember the printer is a heater</strong> – remote starts are convenient, but only start a print when the bed is clear and someone can respond to a problem.</li>
</ul>
<h2>Troubleshooting checklist</h2>
<ol>
<li><strong>Printer shows offline</strong> – check the network menu for an IP address; restart the router and printer.</li>
<li><strong>Pairing code expired</strong> – start the add-printer step again on the printer to get a fresh code.</li>
<li><strong>Upload works but print does not start</strong> – check that the G-code was sliced for that printer model and that the plate is confirmed clear if the printer asks.</li>
<li><strong>No camera image</strong> – check that the camera is registered to the right printer and has network access.</li>
<li><strong>MK3S+ not appearing</strong> – make sure the Raspberry Pi has finished booting PrusaLink and that the serial connection is enabled in the printer&#39;s settings.</li>
</ol>
<h2>Verdict</h2>
<p>Prusa Connect is the easiest way to run a Prusa printer remotely: free, built into every current model and integrated with PrusaSlicer. Use PrusaLink for simple local control, Prusa Connect for remote access and multiple printers, and Prusa Connect Local if you want the Connect dashboard without the cloud. For an overview of the hardware, see our <a href="/printers/prusa-3d-printers/">Prusa 3D printers</a> hub.</p>

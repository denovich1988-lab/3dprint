Конвертер PNG в DDS

Конвертируйте PNG в текстуры DDS для игр и модов. DXT5 — для прозрачности, DXT1 — для самых маленьких файлов, или RGBA без сжатия; мип-карты по желанию.

Конвертируется на вашем устройстве. Ничего не загружается.

Как пользоваться

  1. Загрузите изображение PNG.
  2. Выберите DXT5, DXT1 или без сжатия и решите, нужны ли мип-карты.
  3. Нажмите «Конвертировать в DDS» и скачайте текстуру.

О конвертации PNG в DDS

Что такое файл PNG?

PNG — формат изображений без потерь с прозрачностью. Яркость можно превратить в высоту и сделать рельефы, литофании и штампы. Подробнее о PNG (на английском).

Что такое файл DDS?

DDS — формат текстур для игр. Он хранит сжатые для видеокарты изображения (DXT/BC) и мип-карты, чтобы текстуры быстро загружались.

Что хранит каждый формат

PNG

Пиксели, прозрачность.

Где используется: Везде.

DDS

Сжатые пиксели, мип-карты, иногда кубические карты.

Где используется: Игровые движки, инструменты для модов Skyrim, Fallout, Minecraft Bedrock, авиасимуляторов.

Вопросы и ответы

Это бесплатно?

Да. Без регистрации, без водяных знаков и без наших ограничений на размер файла. Очень большие файлы ограничены только памятью вашего устройства.

Мои файлы загружаются?

Нет. Конвертация выполняется в браузере с помощью JavaScript и WebAssembly. Файл читается с вашего устройства, и результат создаётся там же, поэтому на наш сервер ничего не отправляется.

Какое сжатие DDS выбрать?

DXT5 (BC3) сохраняет плавную прозрачность и подходит для большинства игровых текстур. DXT1 (BC1) даёт самые маленькие файлы, но прозрачность только «есть/нет». RGBA без сжатия точен, но в 4–8 раз больше.

Нужны ли мип-карты?

Большинство игр ожидают мип-карты для текстур, которые видны на разном расстоянии: они уменьшают мерцание. Картинкам интерфейса и иконкам они обычно не нужны.

Какие файлы DDS можно открыть?

DDS с DXT1, DXT3, DXT5 и без сжатия. Файлы BC7 с новым заголовком DX10 пока не поддерживаются.

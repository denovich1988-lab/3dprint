Конвертер SVG в STL

Выдавите SVG в сплошной STL для табличек, логотипов, брелоков, формочек для печенья и трафаретов. Ширина и толщина задаются в миллиметрах.

Обрабатывается на вашем устройстве. Ничего не загружается.

Как пользоваться

  1. Загрузите SVG с залитыми фигурами (текст сначала переведите в кривые).
  2. Задайте ширину и толщину в миллиметрах.
  3. Нажмите «Создать STL» и скачайте файл.

О конвертации SVG в STL

Что такое файл SVG?

SVG — векторный формат изображений. Его залитые фигуры можно выдавить в тело, чтобы напечатать таблички, логотипы, формочки для печенья и трафареты. Подробнее о SVG (на английском).

Что такое файл STL?

STL — самый распространённый формат для 3D-печати. Он хранит поверхность как список треугольников и больше ничего: ни цветов, ни материалов, ни единиц. Его открывает любой слайсер.

Что хранит каждый формат

SVG

Контуры, заливки, обводки.

Где используется: Inkscape, Illustrator, Figma, Cricut Design Space.

STL

Только треугольную геометрию. Бинарный STL примерно в пять раз меньше ASCII STL.

Где используется: Все слайсеры (Bambu Studio, PrusaSlicer, OrcaSlicer, Cura), скачивания с Thingiverse и Printables, экспорт из большинства CAD.

Вопросы и ответы

Это бесплатно?

Да. Без регистрации, без водяных знаков и без наших ограничений на размер файла. Очень большие файлы ограничены только памятью вашего устройства.

Мои файлы загружаются?

Нет. Конвертация выполняется в браузере с помощью JavaScript и WebAssembly. Файл читается с вашего устройства, и результат создаётся там же, поэтому на наш сервер ничего не отправляется.

Почему пропали части моего SVG?

В 3D превращаются только залитые фигуры и линии с обводкой. Текст сначала нужно перевести в кривые (Inkscape: Контур → Объект в контур; Illustrator: Текст → Преобразовать в кривые). Встроенные растровые изображения игнорируются.

Как сделать формочку для печенья или брелок?

Возьмите простой контур. Для брелока выдавите его на небольшую толщину, а для формочки объедините в слайсере или CAD тонкую высокую стенку и широкий бортик.

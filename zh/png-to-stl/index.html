PNG 转 STL 转换器

把 PNG 转成可打印的 STL。标志模式会抬高深色形状，浮雕模式把亮度变成高度，透明区域保持平整。

在你的设备上处理，不会上传任何内容。

样式

使用方法

  1. 上传一张 PNG 图片。
  2. 选择浮雕、光影浮雕或标志/印章，并以毫米设置宽度、底座和高度。修改设置时 3D 预览会同步更新。
  3. 点击“生成 STL”，下载文件交给切片软件。

关于 PNG 转 STL

什么是 PNG 文件？

PNG 是支持透明度的无损图片格式。亮度可以转换为高度，用来制作浮雕、光影浮雕和印章。 了解更多 PNG（英文）.

什么是 STL 文件？

STL 是 3D 打印最常用的文件。它只把表面保存为一组三角形，没有颜色、材质或单位。所有切片软件都能打开。

各格式保存的内容

PNG

像素、透明度。

常用软件： 随处可见。

STL

只有三角形几何。二进制 STL 大约只有 ASCII STL 的五分之一大小。

常用软件： 所有切片软件（Bambu Studio、PrusaSlicer、OrcaSlicer、Cura）、Thingiverse 和 Printables 的下载，以及大多数 CAD 软件的导出。

常见问题

免费吗？

免费。无需注册、没有水印，我们也不设文件大小限制。超大文件只受你设备内存的限制。

我的文件会被上传吗？

不会。转换通过 JavaScript 和 WebAssembly 在你的浏览器中进行。文件从你的设备读取，结果也在你的设备上生成，不会向我们的服务器发送任何内容。

什么样的图片效果最好？

标志和文字请使用高对比度的 PNG（白色或透明背景上的黑色图形）。浮雕用任何照片都可以，但明暗分明的简单图片效果最清晰。

光影浮雕用什么参数打印？

光影浮雕通常用白色 PLA 竖着打印，填充 100%，层高较细（0.12–0.16 毫米），这样厚度差异才明显。也请参考切片软件针对你打印机的推荐设置。

之后还能改尺寸吗？

可以。在这里设置宽度，或在切片软件中缩放 STL。在切片软件中缩放会同时改变厚度，所以厚度最好在这里设置。

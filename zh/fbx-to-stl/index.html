FBX 转 STL 转换器

在浏览器中把 FBX 文件转换为 STL。先在 3D 中预览、检查尺寸，再下载。免费、无需注册，文件不会离开你的设备。

文件在你的设备上处理，永远不会上传。

使用方法

  1. 把 FBX 文件拖到 3D 预览上，或点击“上传模型”。
  2. 检查预览和尺寸。如果模型看起来不对，调整缩放或向上轴。
  3. 点击“转换为 STL”，然后下载 STL 文件。

关于 FBX 转 STL

绑定骨骼的角色会以文件中保存的姿势导出。头发面片或扁平衣物等较薄的部分，可能需要加厚后才能打印。

什么是 FBX 文件？

FBX 是 Autodesk 用于动画和游戏的交换格式，可以包含网格、骨骼、动画和材质。 了解更多 FBX（英文）.

什么是 STL 文件？

STL 是 3D 打印最常用的文件。它只把表面保存为一组三角形，没有颜色、材质或单位。所有切片软件都能打开。

各格式保存的内容

FBX

网格、绑定、动画、相机、材质。

常用软件： Maya、3ds Max、Unity、Unreal Engine、Mixamo、Blender。

STL

只有三角形几何。二进制 STL 大约只有 ASCII STL 的五分之一大小。

常用软件： 所有切片软件（Bambu Studio、PrusaSlicer、OrcaSlicer、Cura）、Thingiverse 和 Printables 的下载，以及大多数 CAD 软件的导出。

常见问题

免费吗？

免费。无需注册、没有水印，我们也不设文件大小限制。超大文件只受你设备内存的限制。

我的文件会被上传吗？

不会。转换通过 JavaScript 和 WebAssembly 在你的浏览器中进行。文件从你的设备读取，结果也在你的设备上生成，不会向我们的服务器发送任何内容。

把 FBX 转换为 STL 会丢失什么？

STL 保存的内容：只有三角形几何。二进制 STL 大约只有 ASCII STL 的五分之一大小。。FBX 中除此之外的信息都会被舍弃。 FBX 是封闭格式。我们可以在浏览器中读取它；写入 FBX 需要 Autodesk 的 SDK，因此不提供 FBX 导出。

为什么模型尺寸不对？

不同格式记录单位的方式不同：STL 没有单位，glTF 使用米，3MF 和 STEP 会记录单位。如果结果看起来小了或大了 1000 倍，请在“缩放”中选择其他选项（例如“米 → 毫米”）后重新转换。

为什么模型是躺着的？

有些格式以 Y 为上（glTF、OBJ、FBX），有些以 Z 为上（STL、3MF、STEP）。“向上轴：自动”会根据目标格式旋转模型。如果想保持原始朝向，请选择“保持不变”。

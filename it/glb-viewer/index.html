Visualizzatore GLB

Visualizza file GLB online senza installare nulla. Ruota e ingrandisci, leggi dimensioni, numero di triangoli e volume, e converti in un altro formato se ti serve.

I file vengono elaborati sul tuo dispositivo e mai caricati.

Converti in

Come si usa

  1. Trascina il tuo file GLB nel visualizzatore o fai clic su «Carica il tuo modello».
  2. Ruota con il mouse o un dito, ingrandisci con la rotella o con due dita e passa alla vista wireframe per controllare la mesh.
  3. Leggi dimensioni, numero di triangoli e volume, salva un PNG o converti il modello in un altro formato.

Domande e risposte

È gratis?

Sì. Niente registrazione, niente filigrana e nessun limite di dimensione imposto da noi. I file molto grandi sono limitati solo dalla memoria del tuo dispositivo.

I miei file vengono caricati?

No. La conversione avviene nel tuo browser con JavaScript e WebAssembly. Il file viene letto dal tuo dispositivo e il risultato viene creato sul tuo dispositivo, quindi nulla viene inviato al nostro server.

Quali formati apre il visualizzatore?

STL, 3MF, OBJ, GLB, glTF, FBX, PLY, DAE, 3DS, USDZ, OFF, AMF, VRML (WRL), STEP, STP, IGES, IGS e G-code, oltre agli archivi ZIP che contengono un modello.

Quanto sono precise le misure?

Le dimensioni vengono direttamente dalle coordinate del file e sono mostrate nelle sue unità (millimetri per la maggior parte dei file di stampa 3D). Il volume è esatto per le mesh chiuse (a tenuta); per quelle aperte è solo una stima.

Posso aprire file enormi?

I file con qualche milione di triangoli si aprono sulla maggior parte dei computer. Le scansioni molto grandi possono essere lente sul telefono, perché tutto gira sul tuo dispositivo.

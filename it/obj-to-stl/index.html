Convertitore da OBJ a STL

Converti file OBJ in STL nel tuo browser. Visualizza l’anteprima 3D, controlla le dimensioni e scarica il risultato. Gratis, senza registrazione, e il file non lascia mai il tuo dispositivo.

I file vengono elaborati sul tuo dispositivo e mai caricati.

Come si usa

  1. Trascina il tuo file OBJ nell’anteprima 3D o fai clic su «Carica il tuo modello».
  2. Controlla anteprima e dimensioni. Regola scala o asse verticale se il modello appare sbagliato.
  3. Fai clic su «Converti in STL», poi scarica il file STL.

Conversione da OBJ a STL

I file OBJ da Blender, ZBrush o scanner 3D spesso includono texture. L’STL conserva solo la geometria, che è ciò che serve allo slicer.

L’OBJ di solito ha l’asse Y verso l’alto. Ruotiamo il modello con Z verso l’alto perché appoggi correttamente sul piano.

Che cos’è un file OBJ?

L’OBJ è un formato 3D testuale supportato quasi ovunque. Memorizza vertici, facce e coordinate texture; i materiali stanno in un file .mtl separato. Altro su OBJ (in inglese).

Che cos’è un file STL?

L’STL è il file più comune per la stampa 3D. Memorizza una superficie come elenco di triangoli e nient’altro: niente colori, materiali o unità. Tutti gli slicer lo aprono.

Cosa conserva ogni formato

OBJ

Geometria, coordinate UV, normali, gruppi. Colori e texture solo tramite il file .mtl e le immagini associate.

Usato da: Blender, Maya, 3ds Max, ZBrush, motori di gioco, app di fotogrammetria e scansione 3D.

STL

Solo geometria a triangoli. L’STL binario è circa cinque volte più leggero dell’STL ASCII.

Usato da: Tutti gli slicer (Bambu Studio, PrusaSlicer, OrcaSlicer, Cura), i download di Thingiverse e Printables, la maggior parte dei CAD in esportazione.

Domande e risposte

È gratis?

Sì. Niente registrazione, niente filigrana e nessun limite di dimensione imposto da noi. I file molto grandi sono limitati solo dalla memoria del tuo dispositivo.

I miei file vengono caricati?

No. La conversione avviene nel tuo browser con JavaScript e WebAssembly. Il file viene letto dal tuo dispositivo e il risultato viene creato sul tuo dispositivo, quindi nulla viene inviato al nostro server.

Cosa si perde convertendo da OBJ a STL?

STL conserva: Solo geometria a triangoli. L’STL binario è circa cinque volte più leggero dell’STL ASCII. Tutto ciò che OBJ memorizza oltre a questo viene scartato.

Perché il mio modello ha la dimensione sbagliata?

I formati gestiscono le unità in modo diverso: STL non ne ha, glTF usa i metri, 3MF e STEP registrano le unità. Se il risultato sembra 1000 volte troppo piccolo o grande, scegli un’altra opzione in Scala (per esempio «Metri → mm») e converti di nuovo.

Perché il mio modello è sdraiato?

Alcuni formati usano Y come asse verticale (glTF, OBJ, FBX), altri Z (STL, 3MF, STEP). «Asse verticale: automatico» ruota il modello in base al formato di destinazione. Scegli «Lascia così» se preferisci l’orientamento originale.

<h2>Who the Prusa MK3 suits today</h2>
<p>A used MK3S+ suits people who want a reliable, well-documented i3 printer with a huge base of guides, spare parts and community mods. It is slower than current CoreXY printers and has no network connection without an add-on. If you buy new, look at the <a href="/printers/prusa-mk4/">Prusa MK4S</a> or the <a href="/printers/prusa-core-one/">Prusa Core One</a> instead.</p>
<h2>Setting up a Prusa MK3S+</h2>
<p>Kits are built with Prusa&#39;s illustrated assembly manual; the assembled version needs only unpacking. After that, the printer&#39;s built-in wizard runs a self-test, XYZ calibration with the SuperPINDA probe, a first-layer calibration to set the Z height, and filament loading. Then print one of the test files from the SD card.</p>
<h2>Connecting the MK3S+</h2>
<p>The MK3S+ prints from the <strong>SD card</strong> (a 16 GB card comes in the box) and uses <strong>USB</strong> for firmware updates. Wi-Fi or Ethernet printing needs an add-on such as a Raspberry Pi running Prusa&#39;s network software. Check sliced files with our <a href="/gcode-to-stl/">G-code to STL tool</a> before you copy them to the card.</p>
<h2>Prusa MK3 manual</h2>
<p>Prusa publishes the MK3S+ assembly manual, user handbook and troubleshooting articles in the Prusa Knowledge Base. For an overview of what it covers, see our <a href="/printers/prusa-mk3s-manual/">Prusa MK3S manual guide</a>.</p>
<h2>Firmware and software</h2>
<p>Firmware is flashed over <strong>USB</strong> with PrusaSlicer, using the file from Prusa&#39;s downloads. Slicing is done in <strong>PrusaSlicer</strong>, which still includes MK3S+ profiles.</p>
<h2>Upgrade paths</h2>
<p>Prusa offers MK3.5, MK3.9 and MK4 upgrade kits, plus an MK3/S to MK4S kit, which reuse the frame and many parts. The successors added a lot: the MK4 (March 2023) brought the Nextruder with load-cell levelling, a 32-bit board and Ethernet, and the MK4S (August 2024) added 360° cooling and a high-flow nozzle.</p>

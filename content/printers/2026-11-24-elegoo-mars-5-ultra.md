**The Elegoo Mars 5 Ultra is a desktop MSLA resin 3D printer with a 7-inch 9K monochrome LCD, a 153.36 × 77.76 × 165 mm build volume and a tilting build plate for faster prints.** Elegoo showed it at Rapid + TCT 2024 and opened pre-orders in June 2024. It suits miniatures, jewellery models and small detailed parts.

## Elegoo Mars 5 Ultra at a glance

| Item | Detail |
|---|---|
| LCD | 7-inch 9K mono, 8520 × 4320 px |
| XY pixel size | 18 × 18 µm |
| Build volume | 153.36 × 77.76 × 165 mm |
| Light source | COB, 405 nm, 25 LEDs |
| Max speed | 150 mm/h |
| Layer thickness | 0.01–0.2 mm |
| Release | Tilting build plate |
| Camera | AI camera |
| Connectivity | Wi-Fi, USB |
| Weight | 8.8 kg |

## Who the Mars 5 Ultra suits

It suits hobbyists who print tabletop miniatures and small detailed models and want automatic levelling and remote monitoring without moving up to a larger, pricier resin printer. The build volume is small, so for bigger models look at the [Elegoo Saturn 4 Ultra](/printers/elegoo-saturn-4-ultra/).

## Mars 5 Ultra features

- **Tilt release:** the build plate tilts to peel each layer from the PFA film, with switchable fast and slow modes. In the Mars 5 line this is only on the Ultra.
- **AI camera:** detects an empty build plate and warping, alerts you to errors and records time-lapses.
- **Auto levelling:** one-click self-check and levelling with a mechanical sensor.
- **Smart sensors:** resin shortage, residue in the vat, levelling failure, power-loss resume, and a pause if the printer reaches 80 °C.
- **Release film reminder** after about 60,000 uses.

## Setting up the Mars 5 Ultra

1. Unpack the printer and remove all protective film and packing pieces.
2. Run the **device self-check** from the touchscreen.
3. Fit the build plate and vat and run **one-click auto levelling**; Elegoo says no manual levelling is needed.
4. Pour resin into the vat up to the marked line and print the test file from the USB drive.
5. Wash and cure the print, wearing gloves when handling uncured resin.

**Tip:** run a resin calibration print (the manual has a section on it) whenever you switch resin brands, so the exposure time matches the new resin.

## Connecting the Mars 5 Ultra

Print from the **USB drive** or send files over **Wi-Fi**. On a network, the printer works with CHITUBOX's network management tools, and you can manage several printers at once (cluster printing). No internet connection is needed for local Wi-Fi printing.

## Mars 5 Ultra manual

The user manual ships printed with the printer and as a file on the included USB drive. It covers the packing list, specifications, self-check, test printing, software setup, network management, the AI camera, resin calibration, firmware upgrades, FAQ and maintenance. Firmware and other downloads are on Elegoo's website.

## Firmware and software

When the printer is online it shows a pop-up when printer or camera firmware updates are available. To update offline, copy the firmware package from Elegoo to a USB drive and choose **Settings → Version Upgrade → Local Upgrade**. Slice in **CHITUBOX** with the ELEGOO Mars 5 Ultra profile.

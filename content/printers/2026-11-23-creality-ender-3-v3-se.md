**The Creality Ender 3 V3 SE is an entry-level open-frame 3D printer with a 220 × 220 × 250 mm build volume, CR Touch auto levelling and a direct-drive Sprite extruder.** Creality released it in 2023 at US$199. It keeps the classic Ender-3 bed size but is faster and easier to set up than older models.

## Who the Ender 3 V3 SE suits

The V3 SE suits beginners and budget buyers who want auto levelling and a quick start. It handles PLA, PETG and TPU. It is less suited to people who want to print remotely – it has no Wi-Fi – or to print ABS without an enclosure.

## Ender 3 V3 SE vs other Ender models

| Model | Max speed | Levelling | Wi-Fi |
|---|---|---|---|
| Ender-3 V2 | 180 mm/s | Manual | No |
| Ender-3 V3 SE | 250 mm/s | CR Touch + auto Z offset | No |
| Ender-3 V3 KE | 500 mm/s | Auto | Yes |

## Assembly and first setup

The printer arrives about 90% assembled:

1. Fix the gantry to the base with three screws on each side.
2. Attach the screen and the spool holder.
3. Set the power supply's voltage switch to your mains (115 V in the US).
4. Switch on and run auto levelling and the auto Z offset.
5. Load filament with the Extrude function – loading and unloading are automatic.
6. Print a file from the SD card.

**Tip:** the strain sensor sets the Z offset for you, so you do not need the paper method used on the original Ender-3.

## Connecting the Ender 3 V3 SE

There is no Wi-Fi or app connection. Slice a model on your computer, save the G-code to the SD card and start the print on the printer's screen with the rotary knob.

## Manual, firmware and slicer

The user manual is on the Creality Wiki under Ender Series → Ender-3 V3 SE → Quick Start Guide, and the support page has downloads and an unboxing video. Firmware updates come from the support page and install in two steps from SD cards: first the screen firmware folder, then the mainboard .bin file. Creality Print is the official slicer; Cura and PrusaSlicer work with a custom profile. Our [G-code to STL converter](/gcode-to-stl/) turns an old print file back into a model.

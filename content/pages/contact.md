**The fastest way to reach my3dprinter.io is by email: hello@my3dprinter.io.** We usually reply within a few working days.

## What to include

| Topic | Please tell us |
|---|---|
| A file will not open | File format, approximate file size, the program that created it, your browser and device |
| A conversion looks wrong | Source and target format, the settings you chose and what looks wrong (a screenshot helps) |
| A correction to a guide | The page address, what is wrong and, if you can, where the correct information is published |
| A new tool or format | The format you need and what you use it for |
| Privacy questions | See our [privacy policy](/privacy/) first; then write to the same address |

## Please do not send files you need to keep private

Our tools work without uploads, so we rarely need your actual file. A description or a screenshot is usually enough. If we do need a sample to fix a bug, we will ask, and you can send a simplified test file instead of your real design.

## Before you write

- Many questions are answered on the tool page itself, in the "Common questions" section.
- For printer hardware faults, warranty or firmware problems, contact the printer's manufacturer. We are independent and cannot service printers.
- Check our [file formats guide](/formats/) to see which formats the tools can read and write.
